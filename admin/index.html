Připojení

Změny se ukládají přímo do repozitáře na GitHubu. Web se po zveřejnění aktualizuje sám, obvykle do minuty.

Token zůstává jen v tomto prohlížeči a posílá se pouze na api.github.com.
Jak získat token (jednou):
  1. GitHub → Settings → Developer settings → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → vyber jen repozitář s webem.
  3. Permissions → Repository → Contents: Read and write. Nic dalšího.
Nepoužívej „classic“ token — ten má přístup ke všem tvým repozitářům.

Ukládá do složky na tomto počítači přes testovací server (dev_server.py). Na internet se nic neposílá.
