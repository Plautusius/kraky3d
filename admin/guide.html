2. Přidání nového projektu

Krok 1: Otevři projects.json

Soubor najdeš v: data/projects.json

Můžeš použít jakýkoliv textový editor (VS Code, Notepad++, atd.)

Krok 2: Přidej nový projekt

Zkopíruj tento vzor a uprav hodnoty:

{
    "id": 10,  // Unikátní číslo (vyšší než předchozí)
    "title": "Název projektu",
    "category": "character",  // character / environment / product
    "software": "blender",  // blender / 3dsmax
    "description": "Popis projektu...",
    "thumbnail": "URL nebo cesta k náhledu",
    "images": [
        "URL obrázku 1",
        "URL obrázku 2"
    ],
    "tags": ["Blender", "Character", "PBR"],
    "has3D": true,  // true pokud máš 3D model
    "modelUrl": "assets/models/nazev.glb",
    "date": "2025-12-22"
}
Pozor na syntaxi!
- Každý projekt kromě posledního musí končit čárkou
- Textové hodnoty musí být v uvozovkách "text"
- true/false a čísla jsou bez uvozovek

4. Přidání obrázků

Varianta A: Online obrázky (doporučeno)

Nahraj obrázky na službu jako:

  • Imgur - zdarma, bez registrace
  • ImgBB - zdarma hosting obrázků
  • Cloudinary - profesionální řešení

Pak použij přímý URL odkaz v JSON.

Varianta B: Lokální obrázky

Ulož obrázky do assets/renders/ a použij cestu:

"thumbnail": "assets/renders/projekt1_thumb.jpg"
Doporučené rozměry:
- Thumbnail: 800x500 px
- Galerie: 1920x1080 px (nebo větší)

5. Přidání 3D modelů

Export z Blenderu

  1. File → Export → glTF 2.0 (.glb/.gltf)
  2. Format: glTF Binary (.glb)
  3. Zaškrtni: Apply Modifiers, +Y Up
  4. Export

Export z 3DS Max

  1. Použij plugin Babylon.js Exporter
  2. Nebo exportuj do FBX a převeď pomocí online konvertoru

Model ulož do assets/models/ a nastav v JSON:

"has3D": true,
"modelUrl": "assets/models/muj_model.glb"
Tip pro optimalizaci:
- Max. velikost souboru: 10-20 MB
- Sniž počet polygonů pomocí decimate modifier
- Komprimuj textury (max 2K rozlišení)

7. Nahrání na GitHub

Přes GitHub Desktop (nejjednodušší)

  1. Otevři GitHub Desktop
  2. Vyber změněné soubory
  3. Napiš popis změny (např. "Přidán nový projekt")
  4. Klikni "Commit to main"
  5. Klikni "Push origin"

Přes příkazovou řádku

git add .
git commit -m "Přidán nový projekt"
git push

8. Časté problémy

Projekty se nezobrazují

  • Zkontroluj JSON syntaxi na jsonlint.com
  • Ověř, že všechny URL obrázků fungují
  • Otevři konzoli prohlížeče (F12) a hledej chyby

3D model se nenačítá

  • Ověř, že soubor je ve formátu .glb
  • Zkontroluj cestu v JSON
  • Model může být příliš velký - optimalizuj

Změny se neprojevují

  • Vymaž cache prohlížeče (Ctrl+Shift+R)
  • Počkej pár minut po push na GitHub
